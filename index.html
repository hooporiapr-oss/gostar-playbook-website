The Programs

Pick your court.

Every program runs on the same escalating philosophy — a round only gets harder, and the scoreboard remembers everyone who's played. Where they differ is who they're built for.

01
Reaction Velocity
Four reaction disciplines

Four distinct reaction-time games — go/no-go restraint, pure speed, directional recall with the map reshuffled every round, and a moving target that never sits still. Played on their own or chained into one four-quarter run with a combined final score.

  • Four games, each testing a different edge of reaction speed
  • Practice any single game, or run the full four-quarter chain
  • Live standings, ranked by best score
  • Built for individual and head-to-head play

02
Dynamic Memory
Four-quarter memory system

A dedicated memory program built around four distinct quarters — recall, reflex, replay, and recognition — playable individually or run together as one complete game with a combined final score.

  • Four quarters, each a different memory discipline
  • Practice any single quarter, or play the full game
  • Standings for every quarter and the combined score
  • Built for repeatable, focused training
Enter Dynamic Memory → memorybball.com
03
Swish Basketball
A growing memory streak, scored like a 3-point contest

One cumulative sequence that grows by a tap every possession — watch it, then repeat it back. Every correct tap is a made 2-pointer, and finishing a possession clean adds a 3-pointer on top. In essence, it's a 3-point shot contest — the longer the streak runs, the more 3-pointers end up on the board.

  • Every tap scores — a 2-pointer the instant it lands
  • Every finished possession adds a bonus 3-pointer
  • One growing sequence — no reset, no fixed finish
  • Live standings, ranked by total points
Enter Swish Basketball → hooporia.com
